THREAD — Clothing shopping website
HTML, CSS, and vanilla JavaScript. No dependencies.

Extract the ZIP and open index.html in a modern browser.
Search and filter the sample products, select sizes, add to your bag, and change quantities. Cart saves locally when browser storage is available.
Checkout is a demo only; no payment, inventory, account, or real ordering service is connected. Catalog photos are illustrative and sample prices are fictional.
